String Art

String art is a form of artwork where pegs are placed on a canvas, and a single-color thread is ran from peg to peg in a continuous line. The overlapping threads progressively create a recognisable image. Populariation of this technique is often attributed to Petros Vrellis.

This tool can generate string art from any picture you upload. It is an archive of this original tool by Jeremie Piellard, with minor tweaks to better suit my use case. You can donate to Jeremie here.

The monochrome mode uses a single thread, while the color mode uses 3 distinct threads. The result can be exported as an SVG, or a text file giving the sequence of pegs used to create the image.
